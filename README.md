# EVENTORIA · Оновлена версія 10.0

Сайт для організації подій. Готовий статичний проєкт із 30 послугами (10 весільних, 10 корпоративних, 10 дитячих), подробицями про кожен захід, портфоліо, блогом, формою запиту, окремою сторінкою контактів і демоадмінпанеллю.

## Як відкрити
1. Розпакуйте ZIP в окрему папку.
2. Двічі натисніть OPEN_SITE.bat або відкрийте index.html у Chrome.
3. Розділи сайту: Головна → index.html; Послуги → catalog.html; Про нас → about.html; Контакти → contact.html; Оформити заявку → order.html.
4. Для входу до демонстраційної адмінпанелі відкрийте OPEN_ADMIN.bat або admin.html.
   Демо-логін: admin
   Демо-пароль: Eventoria2026!

## Як змінювати фотографії
1. Відкрийте OPEN_ADMIN.bat → увійдіть в адмінпанель.
2. Натисніть «📷 Завантажити фото» або відкрийте photo_admin.html.
3. Виберіть «Послуги» або «Портфоліо», потім потрібну картку.
4. Завантажте фото з комп’ютера, виберіть обкладинку, порядок кадрів і збережіть файли у папку сайту або скачайте ZIP зі змінами.
5. Після збереження обов’язково перевірте, що `photo-config.js` і папка `assets/photos/custom` оновилися. Вони містять ваші заміни фотографій.

Можна редагувати назви, ціни, описи, місця проведення, програму заходу й додаткові можливості у розділі «Послуги» адмінпанелі. Усі зміни текстів через звичайну адмінпанель зберігаються тільки у браузері поточного пристрою. Щоб вони відображалися на публічному сайті для всіх, потрібен бекенд або експортування й публікація відредагованих даних.

## Для публікації
Файл index.html, order.html, contact.html, about.html, editorial-data.js, app.js, styles.css, photo-config.js, data.js та папка assets повинні бути в корені публікації.
Налаштування GitHub Pages: Settings → Pages → Deploy from branch → main → / (root).
Після оновлення перезавантажте сайт через Ctrl+Shift+R.

## Важливі обмеження
- Це навчальний демопроєкт, а не готовий комерційний бекенд.
- Ім’я/телефон/email менеджера, відгуки та ціни потребують перевірки й заміни на ваші реальні дані перед публікацією.
- Заявки та чат зберігаються лише у браузері, email-повідомлення менеджеру не надсилаються.
- Пароль демоадмінпанелі не є справжнім захистом. Для публічного керування потрібна серверна авторизація та база даних.
- Фото — ілюстративні референси; не слід представляти їх як реально проведені агенцією заходи.
- Реальна тривалість, можливість проведення та ціна узгоджуються індивідуально.
