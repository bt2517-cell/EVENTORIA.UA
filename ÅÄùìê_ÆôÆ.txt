EVENTORIA 10.0 — ІНСТРУКЦІЯ

1) Розпакуй ZIP.
2) Відкрий OPEN_SITE.bat (або index.html).
3) На сторінці «Про нас» є багато нової інформації про студію та процес.
4) У «Послугах» натисни «Детальніше» — побачиш програму, локацію, тривалість, умови підготовки.
5) «Контакти» — окрема сторінка з фотографією Анни.
6) «Замовити свято» — окрема сторінка з формою заявки (вона демонстраційна!).
7) Для фото відкрий OPEN_ADMIN.bat → логін admin, пароль Eventoria2026! → «📷 Завантажити фото».
8) Файли твоїх фото збережені в assets/photos/custom, їхні налаштування — у photo-config.js.
9) Для GitHub Pages завантаж усі розпаковані файли, щоб index.html був у корені репозиторію.

Для тестування на комп’ютері Python не потрібен. START.bat запускає локальний сервер і потребує Python, тому якщо Python не встановлено, використовуй OPEN_SITE.bat.

Увага: демоадмінпанель не змінює опублікований сайт автоматично. Заявки з форми не надсилаються менеджеру без сервера.
