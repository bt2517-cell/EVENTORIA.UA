EVENTORIA — оновлення входу та профілю

1. Розпакуйте ZIP.
2. Завантажте усі файли з архіву в КОРІНЬ репозиторію EVENTORIA.UA (поруч з index.html).
3. НЕ перезаписуйте supabase-config.js; його тут немає.
4. Після GitHub Pages обновіть сайт Ctrl+F5.
5. Натисніть іконку користувача у верхньому меню — відкриється вікно входу/реєстрації.
6. Після входу іконка показує меню: Мої дані / Мої замовлення / Вийти.
7. Замовлення відображаються лише після входу, база даних Supabase зберігається незмінною.

ВАЖЛИВО: адміністратор сайту як і раніше бачить лише локальні демо-заявки. Для серверної панелі менеджера потрібна окрема захищена розробка.
