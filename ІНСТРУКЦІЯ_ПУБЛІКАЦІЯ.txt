EVENTORIA — очищена версія для GitHub Pages

У цьому архіві — всі файли сайту, включно з обкладинками, галереями та фото Анни.
Прибрано тільки 10 старих фото з assets/photos/custom, яких немає у посиланнях сайту.
Великі зображення оптимізовано для сайту (максимальна сторона 2200 px, без обрізання).
Файли JS, HTML, CSS та ваш photo-config.js не змінено.

Як оновити GitHub без видалення репозиторію:
1) У GitHub відкрийте свій існуючий репозиторій і гілку main.
2) Розпакуйте EVENTORIA_GITHUB_UPLOAD_1.zip. На сторінці Code → Add file → Upload files
   завантажте весь вміст цієї папки (НЕ сам ZIP). Натисніть Commit changes.
3) Повторіть для EVENTORIA_GITHUB_UPLOAD_2.zip. Дочекайтеся зеленого статусу Actions.
4) Settings → Pages → Deploy from branch → main → /(root).
5) Перевірте сайт у приватній вкладці, щоб виключити локальні збережені дані.

Важливо: не кладіть папки пакета всередину іншої папки в GitHub.
Завантажувати слід файли так, щоб index.html опинився в корені репозиторію.
Старі невикористовувані фото можуть ще залишатися на GitHub; їх можна видалити пізніше.
Для захисту вашої роботи оригінальний архів не змінювався.

Увага: зміни текстів, зроблені лише в браузері (localStorage), не потрапляють у GitHub автоматично.
